# 核心异动票跟踪（Watchlist）

## 定位

跟踪**进过异动的核心票**在见顶后的调整位置，长期积累事实，供人工判断何时进入观察窗口。

- **独立决策入口**，与决策卡同级：不写 `data/review_run.sqlite`、不创建 publication、不进入 `reports/daily/`，不构成正式复盘。
- **只记录事实与客观分层**：不做形态成立判定、不给买卖建议、不设"可买"阈值。
- 规则出处：`stock-review.md` STEP 9 模式 9「前期核心 21 日线低吸（最起码要进过异动监管）」。本模块把这条从"检查清单"落成可计算的事实表。

## 产物与命令

| 命令 | 作用 | 产物 |
| --- | --- | --- |
| `python -m stock_review.watchlist candidates --date <日期> [--top N]` | 自动收集异动候选，供审核 | `data/watchlist/candidates/<日期>.json` |
| `python -m stock_review.watchlist pool-add --code <代码> --name <名称> --reason <原因>` | 审核通过后入池 | `data/watchlist/pool.json` |
| `python -m stock_review.watchlist pool-list` | 查看池成员 | — |
| `python -m stock_review.watchlist pool-status --code <代码> --status paused\|removed\|active --reason <原因>` | 变更成员状态 | `data/watchlist/pool.json` |
| `python -m stock_review.watchlist run --date <日期>` | 对池内启用对象出跟踪表 | `reports/watchlist/<日期>.md` + `data/watchlist/<日期>.json` |

## 口径

### 异动认定（交易所公开口径）

偏离值 = 同交易日「个股涨跌幅 − 基准指数涨跌幅」，逐日累计。

| 档位 | 认定条件 |
| --- | --- |
| **严重异常波动** | 连续 10 个交易日偏离值累计 ≥ **+100%**，或连续 30 日 ≥ +200% |
| **异常波动** | 连续 3 个交易日偏离值累计达板块阈值（主板 20%、创业板/科创板/北交所 30%） |

基准指数按板块配对：沪市主板→上证指数、科创板→科创50、深市主板→深证成指、创业板→创业板指、北交所→北证50。
模块对最近约 90 个交易日逐日扫描，记录每一次触发的日期与档位，并取最高档作为该票的异动档位。

### 均线与位置

核心跟踪位置为 **MA21**（21 日前复权收盘均线）。同时给出 MA5、MA10。

位置分层（距 MA21 的收盘偏离）：

| 位置 | 条件 |
| --- | --- |
| 远离均线 | ≥ +8% |
| 接近均线 | +3% ~ +8% |
| 到线 | −3% ~ +3% |
| 跌破均线 | ≤ −3% |

> **21 日线是更优的观察位置，但不是唯一位置。** 行情好或时机到时，形态可能在**未到 21 日线**前即因放量中阳启动；因此提醒同时覆盖「到线/跌破」与「放量中阳」两类，详见下文。

### 量能与形态事实

- **量比** = 当日成交量 ÷ 前 5 个交易日成交量均值（不含当日）。
- **放量**：量比 ≥ 1.5（展示口径，非判定）。
- **中阳**：当日涨幅 ≥ 5%（展示口径，非判定）。
- **收盘强度** =（收盘 − 最低）÷（最高 − 最低），衡量尾盘承接位置。

区间极值取最近 **60 个交易日**，用于给出「区间低点→高点（涨幅）」与「距高点交易日数」。

## 跟踪池

- 池文件：`data/watchlist/pool.json`，成员字段含代码、名称、板块、基准指数、入池日期、入池原因、状态。
- **候选由模块自动收集**（龙虎榜上榜 + 涨停池连板 + 强势股池），报用户审核后由 `pool-add` 显式加入；模块不会自动入池。
- 入池原因必填；代码无法判定板块、或已存在时拒绝入池。
- 状态：`active`（默认，参与出表）、`paused`（暂停，保留记录但不采集）、`removed`（退出）。

## 提醒机制

`run` 会在跟踪表首节输出提醒行，两类：

1. **位置提醒**：`[到线]` / `[跌破]` / `[接近]`——距 21 日线的客观位置。
2. **放量中阳提醒**：`[放量中阳]`——当日同时放量（量比 ≥ 1.5）且收中阳（涨幅 ≥ 5%），提示形态可能不等 21 日线即启动。

提醒只描述客观位置与当日量价状态，不构成买卖建议。

## 数据源

全部走 AKShare 直连（可自动化，无需交互式连接器）：

| 数据 | 接口 |
| --- | --- |
| 个股前复权日线 | `stock_zh_a_daily`（`adjust="qfq"`，新浪） |
| 基准指数日线 | `stock_zh_index_daily`（新浪） |
| 龙虎榜日榜 | `stock_lhb_detail_em`（含上榜原因，即偏离值类异动认定） |
| 资金流向 | `stock_fund_flow_individual`（同花顺，主力净额） |
| 候选粗筛 | `stock_zt_pool_em`、`stock_zt_pool_strong_em` |

前复权口径已与通达信前复权在 301251 / 301132 / 300413 三只样本上逐位核对一致（区间极值、MA21、量比）。

## 已知限制

1. **前复权价随最新交易日滚动**：除权除息会调整历史价格，历史绝对价格可能与当日快照不同；跟踪以比例与位置为主，不受影响。
2. **偏离值为自算**：与交易所公布的异常波动公告可能存在细微差异（如停牌、无涨跌幅限制日处理），以交易所公告为最终口径。
3. **阈值属自定展示口径**：位置分层（±3% / ±8%）、放量（1.5 倍）、中阳（5%）均为模块自定，用于分层提示而非判定；调整属行为变更，须单独评审。
4. **资金流向为当日快照**：`stock_fund_flow_individual` 只返回当日，不能用于历史日期补跑。
5. **候选粗筛以龙虎榜为主**：未接入公告全文与全市场区间涨幅扫描，可能漏掉仅触发严重异常波动而未上榜的票。
6. **不做形态成立判定**：表内"位置""放量""中阳"是客观分层与事实标记，不构成"可以买"的结论。
